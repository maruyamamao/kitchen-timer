# 電卓風キッチンタイマー

## 概要
C#とWPFを使用して開発した、電卓のようなボタン配置とデザインを採用したキッチンタイマーアプリケーションです。数字ボタンによる時間入力やカウントダウン、アラーム機能を備えています。

## 主な機能
- 数字ボタンによるタイマー時間の入力
- カウントダウン機能
- タイマーの開始・停止・リセット
- 設定時間の経過を知らせるアラーム機能

## 使用技術
- プログラミング言語：C#
- フレームワーク：WPF
- 画面設計：XAML
- 開発環境：Visual Studio

## 開発の経緯
C#とWPFの学習を通じて、実用的なデスクトップアプリケーションを制作するために開発しました。電卓のような数字ボタンを配置することで、直感的に時間を入力できるデザインを目指しました。

## 工夫した点・学んだこと
数字ボタンからの入力処理やタイマーの状態管理、画面表示の更新などを実装しました。また、ボタン操作に応じて適切な処理が行われるように、イベント処理や動作確認を繰り返しながら改善しました。
